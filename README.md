# 💰 Simulador de Negociações

Projeto desenvolvido como parte dos estudos e prática de **TypeScript**, simulando uma página de negociações financeiras.

A aplicação permite informar **data, quantidade e valor** para realizar uma simulação de negociação, apresentando os dados de forma organizada na interface.

## 🚀 Sobre o projeto

O projeto foi desenvolvido com o objetivo de praticar conceitos fundamentais do **TypeScript** aplicados a uma aplicação web.

Durante o desenvolvimento, foram trabalhados conceitos como:

- Tipagem de dados
- Interfaces e tipos
- Classes e métodos
- Manipulação do DOM
- Organização de código
- Compilação de TypeScript para JavaScript
- Integração entre TypeScript, HTML e CSS

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- TypeScript
- Bootstrap

## 📋 Funcionalidades

- Inserção da data da negociação
- Definição da quantidade de negociações
- Inserção do valor
- Simulação da negociação
- Exibição das negociações realizadas na página

## 💻 Como executar o projeto

### 1. Clone o repositório

```bash
git clone https://github.com/gabriel-pereira0/Projeto_Negociacoes.git
```

### 2. Acesse a pasta da aplicação

```bash
cd Negociacoes
```

### 3. Instale as dependências da aplicação

```bash
npm install
```

### 4. Inicie a aplicação TypeScript

```bash
npm start
```

### 5. Inicie o servidor da API

Abra **outro terminal** e acesse a pasta `servidor-api`:

```bash
cd Negociacoes/servidor-api
```

Instale as dependências da API:

```bash
npm install
```

Inicie o servidor:

```bash
npm start
```

**Importante:** mantenha os dois terminais abertos enquanto estiver utilizando a aplicação, pois a aplicação TypeScript e o servidor da API precisam estar em execução simultaneamente.

A aplicação será disponibilizada localmente pelo servidor de desenvolvimento.

## 📚 Objetivo

Este é um **projeto de prática e aprendizado**, desenvolvido durante os estudos de TypeScript.

A ideia principal é colocar em prática os conceitos aprendidos e evoluir gradualmente na construção de aplicações web utilizando tipagem estática e boas práticas de desenvolvimento.
